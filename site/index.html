How it works

Agents connect out. Nothing connects in.

Managed machines Linux & Windows agents
→
Outbound WebSocket Go hub + SQLite
→
TLS termination Caddy HTTPS proxy
→
Your browser Dashboard

Agents initiate the connection, so managed machines need no inbound agent port. The browser uses the hub API and an SSE stream. The Compose stack packages Caddy, the hub, and the Next.js dashboard; agents remain native services.

Security

Self-hosted, role-based, and reported in the open

BloxOS is self-hosted and role-based, with viewer, operator, and admin permissions. Signed agent updates ship with rollback protection. Report vulnerabilities privately rather than through public issues.
